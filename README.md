# Solar PV Installation Monitoring (Block 1 and Block 5)

Web app for recording Mounting Structure and PV Module installation status per table on an interactive keyplan.

- **This repository holds the web page code and the drone photos in encrypted form.** Table IDs, keyplan geometry, statuses, users and companies are stored in the project's Supabase database and are shown only after login.
- **Drone photos** (`drone/`) are cut into 512 px picture tiles aligned to the keyplan in metres (5 cm per pixel at the finest level) and encrypted with AES-256-GCM. `drone/photos.json` lists the photos (block, date, tile grid, key id, and the keyplan sheet size the photo is placed on: a photo is shown only when the block's keyplan in the database has that size, so a photo made for a newer drawing waits until its database update is run; `drone/index.json` is the older list, Block 1 only, for app copies that have not reloaded yet). The key is kept in the database (update 11) and is given only to signed-in users, so the tiles cannot be viewed by visitors; the app shows a photo only when its key id matches the key it received. `tools/drone/` holds the scripts that align a new photo to the keyplan and make its tiles (no keys or project data). From database update 13 an administrator can also add a photo in the app (Admin > Drone photos): block, date taken and file (GeoTIFF, PNG or JPG); the browser places it on the keyplan (from the GeoTIFF's GPS position when the block's position is known, otherwise by two points the administrator marks), makes the same encrypted tiles and uploads them to Supabase Storage (bucket `pvm-drone`, one folder per photo); `get_drone_photos` lists them for signed-in users.
- `config.js` contains the Supabase project URL and its public *publishable* key. That key is designed to be public: every read and write is checked inside the database and needs a valid login.
- Hosted with GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).

- **Installs like an app** on Android, iPhone, iPad and computers, straight from the browser (no app store): the menu item *Install the app on this device* shows the steps for each device and a QR code of the link.
- **Works without signal.** `sw.js` keeps the app's own files on the phone; `offline.js` keeps the data the user opened and the updates saved without signal in the phone's storage (IndexedDB) and sends them when the connection is back (database function `sync_offline`, update 10). Project data saved on a phone is removed when the user logs out.

Files: `index.html` (page), `app.js` (keyplan, dashboard, admin), `piles.js` and `piles-pages.js` (Piles module), `offline.js` (working without signal), `install.js` (install on phones, tablets and computers; QR code of the link; new-version notice), `drone.js` (drone photo under both keyplans: decrypts and draws the tiles, background menu, saving the photo for use without signal), `drone-upload.js` (Admin > Drone photos: reads GeoTIFF/PNG/JPG in the browser, placement, tiles, encryption and upload; loaded only on that page), `sw.js` (app files kept on the phone), `qrcode.js` (QR code generator by Kazuhiko Arase, MIT licence, see `qrcode.LICENSE.txt`), `styles.css` (layout), `config.js` (connection), `manifest.webmanifest` and icons (Add to Home Screen).
